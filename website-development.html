Overview

I developed an interactive e‑commerce style website inspired by traditional Maheshwari sarees. The project focused on presenting heritage textile aesthetics through a modern, performant front‑end experience with clean product layouts, responsive design, and intuitive navigation.

Features & Interaction

The site includes dedicated product interaction pages where users can view saree details (fabric composition, weave pattern, color palette) and add selected items to a prototype cart flow. Image focus states, hover reveals, and structured metadata improve decision confidence while maintaining visual storytelling of the craft.

Implementation Highlights

  • → Responsive grid layout for saree catalog enabling seamless mobile and desktop browsing
  • → Interactive product cards with hover states, focused imagery, and quick spec snippets
  • → Prototype cart flow supporting add/select actions for multiple sarees
  • → Semantic structuring of product data (weave, motif, blend, price placeholder)
  • → Performance-focused styling using lightweight utility classes and minimal scripts
