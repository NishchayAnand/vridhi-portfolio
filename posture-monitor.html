Posture Monitor

2024 • Wearable Tech

Overview

A shoulder-worn device that monitors posture in real-time using flex sensors and an IMU. The system tracks spine angle and shoulder position, providing gentle haptic feedback when poor posture is detected.

Technical Details

Built with Arduino Nano 33 IoT and rechargeable battery for all-day wear. The device uses real-time sensor fusion to accurately track posture changes and provides gentle vibration alerts for correction.

Key Features

  • → Real-time posture tracking with flex sensors and IMU
  • → Haptic feedback for posture correction
  • → Ergonomic shoulder-worn design
  • → All-day battery life
  • → Arduino Nano 33 IoT platform
