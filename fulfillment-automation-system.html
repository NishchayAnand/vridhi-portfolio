Fulfillment Automation System

2024 • Supply Chain Tech

Project Snapshot

I built a lot-allocation assistant for a fulfillment floor that removes the manual guesswork from matching orders to fabric lots. The dashboard ingests daily requirement files, surfaces conflicts, and generates a queue of approved picks that warehouse teams can execute without cross-checking spreadsheets.

Workflow Design

  • → Single upload entry point that validates lot availability, size breaks, and reservation rules before the picking window opens.
  • → Interactive Streamlit screens highlight flagged orders, letting planners resolve shortages or substitute lots with a few clicks.
  • → Automated export sends the confirmed pick list to the warehouse in their existing format so no downstream change management was required.

Build Notes

The stack combines FastAPI for the rules engine, Streamlit for rapid UI prototyping, and PostgreSQL for audit trails. Modular services handle data validation, allocation logic, and reporting, letting me iterate on planner feedback without touching the full pipeline each sprint.

Outcomes

  • → Cut lot-mixing incidents to nearly zero by enforcing reservation rules before picks leave the planning table.
  • → Reduced daily planning time from 2 hours to under 30 minutes thanks to clear exception queues.
  • → Documented API endpoints and data contracts so the tool can plug into ERP integrations when the team is ready.
