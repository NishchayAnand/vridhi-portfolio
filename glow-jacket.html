Glow Jacket

2024 • Wearable Tech

Overview

An interactive wearable that integrates WS2812 addressable LEDs with motion and touch sensors to create responsive lighting patterns. The jacket features low-power design with rechargeable battery, durable conductive thread sewing for LED connections, and comfortable placement that doesn't interfere with movement.

Technical Details

Built with ESP32 for wireless control and custom animations. The design prioritizes durability and comfort, ensuring the technology integrates seamlessly into everyday wear.

Key Features

  • WS2812 addressable LED integration
  • Motion and touch sensor responsiveness
  • Low-power rechargeable battery system
  • Durable conductive thread construction
  • ESP32-based wireless control
