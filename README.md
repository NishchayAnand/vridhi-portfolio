# Fashion Tech Portfolio — [Your Name]

A simple, responsive portfolio template for a fashion technology student built with Tailwind CSS (via CDN). Use this as a starting point to showcase projects (wearables, e-textiles, material research) and contact info.

## Files

- `index.html` — main single-page portfolio.

## How to use

1. Open `index.html` in your browser. (Double-click or `open index.html` on macOS.)

2. For local development with a simple static server, run:

```bash
a# from the project folder
cd /Users/nishchayanand/Documents/projects/animation-website
# Python 3
python3 -m http.server 8000
# then open http://localhost:8000 in your browser
```

3. To publish: push to a GitHub repository and enable GitHub Pages (use `gh-pages` branch or the `main` branch `/` root). Alternatively deploy to Netlify or Vercel.

## Customize

- Replace the placeholder text and images in `index.html` with your own portfolio pieces.
- If you prefer to build Tailwind locally for production (smaller CSS bundle), set up a Node project and PostCSS; see Tailwind docs: https://tailwindcss.com/docs/installation
